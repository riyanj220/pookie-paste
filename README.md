# Pookie Paste

A lightweight and fast clipboard history manager for Linux.

Inspired by Windows Clipboard History.

## Vision

Pookie Paste aims to bring a simple, fast, and reliable clipboard history experience to Linux users.

The goal is to make clipboard management feel native:

- Press a shortcut
- Browse previous clipboard items
- Select an item
- Paste instantly

Without unnecessary complexity or heavy background processes.
